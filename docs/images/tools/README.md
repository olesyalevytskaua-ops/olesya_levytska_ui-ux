# Tool icons

Brand SVGs sourced from the Simple Icons npm package (versions 16.0.0 and 11.15.0), distributed under CC0-1.0: https://github.com/simple-icons/simple-icons

Icons are stored locally and rendered in the current text color for both themes. Brand names and marks belong to their respective owners. FigJam and Figma Make use the Figma company mark; Claude uses the Claude symbol supplied by Olesya.

Midjourney uses a locally drawn sailboat pictogram.

Higgsfield uses the monochrome mark from Dashboard Icons (homarr-labs/dashboard-icons, Apache-2.0): https://github.com/homarr-labs/dashboard-icons
