01 /

Recipes we save.
And never cook.

I wanted a beautiful personal cookbook. Instead, everything I wanted to cook lived somewhere else.

Recipes arrive from everywhere: Instagram, TikTok, screenshots, friends' messages, websites and handwritten notes. I save a dish in the moment, but when I finally want to cook it, I can't find it — or I have to piece together the ingredients and method from several images.

Misemio is my second independent product after Pockette. I wanted the same simplicity of access, but with the character of a beautifully printed cookbook: a calm, personal space rather than another endless recipe feed.

What if saving a recipe could take seconds — and the result felt like a cookbook you made yourself?PRODUCT HYPOTHESIS · NOT YET USER-VALIDATED

02 /

The screenshot
collector.

“My camera roll is half recipes.”

I mapped a provisional persona: a home cook who collects recipes from Instagram, TikTok and friends. She's inspired when she sees a dish, uneasy when it disappears into her screenshots, overwhelmed when deciding what to cook at 6 pm, and proud when a recipe becomes her own.

The accompanying empathy map is based on product assumptions and our concept work, not a completed user interview study. It helped focus the solution on three meaningful experiences instead of chasing a larger set of features.

04 /

Save first.
Organise later.

This became the organising principle: importing a recipe never requires users to choose a collection up front. “Unsorted” is a safe default, not a punishment. Collections are completely user-named, just like Pinterest boards, rather than imposed meal categories.

Library

  • Today's pick
  • Recently saved
  • Search + filters
  • Recipe details
  • Cook mode

Collections

  • All recipes · automatic
  • Favorites · automatic
  • Unsorted · automatic
  • Custom names + covers
  • Reorder + rename

Import

  • Screenshots, including multiple images
  • Link import
  • Review + edit
  • Optional collection

Me

  • Personal library
  • Appearance
  • Settings
  • Export + backup
UX detail: uncertain extraction isn't silently accepted. If a screenshot could say “1 tbsp” or “4 tbsp,” the review screen should flag it and offer choices, rather than hiding uncertainty or blocking the entire save.
05 /

Made to feel
like a cookbook.

We explored warm sage minimalism, but the turning point was the editorial journal reference I chose: oversized italic serif titles, restrained monospaced labels, warm paper and generous negative space. Instead of generic dashboard cards, recipes feel like pages and collections feel like chapters.

The name evolved through several rounds — Mise, MySageNotes, MyTastyNotes, SmachnoBox — before becoming Misemio. The final wordmark brings together the culinary idea of mise en place and the personal feeling of mio.

Cormorant Garamond carries the editorial voice; DM Sans handles reading; DM Mono marks navigation and metadata. Contrast, legibility and reduced-motion support remain part of the design brief, not optional polish.

06 /

From capture
to cooking.

The interface exploration covers the full journey, from discovering a recipe and editing its details to custom collections, cook mode and grocery planning. The screens below are real design/prototype captures from the project repository, not claims of fully working flows.

Import — the most important flow to validate next. The PDF explores selecting multiple screenshots, processing the content, highlighting uncertain amounts, correcting the parsed recipe, and saving to Unsorted. Real automated extraction from screenshots and websites isn't working yet.
07 /

Choosing what
not to add.

COLLECTIONS

Not another photo grid.

Compared three structures: list with covers, typographic index and rich image previews. The selected prototype uses a numbered editorial index for scanability.

IMPORT

No required sorting.

Everything can go to Unsorted. Custom collections are optional and can be created later.

COOKING

Not a long recipe page.

Cook mode isolates one step, keeps text large and introduces a timer only when useful.

The wider PDF also explores a share-sheet entry, nutrition estimates, export formats and grocery aggregation. These are design explorations, not a promise that the entire set has been implemented.

08 /

Beautiful is
only the beginning.

Misemio is an in-development UI concept and front-end prototype, not yet a functioning end-to-end recipe product. The immediate milestone is a reliable Screenshot → Review → Edit → Save → Find → Cook flow. After that: real-world import accuracy, user testing, collection organisation behaviour and accessible device testing.

What is proven — and what isn't The repository contains designed screens, code and design-system documentation. The user journeys, persona and value proposition remain hypotheses until we can test with people. Screenshot/link extraction is simulated, and the full prototype is not yet reliably functional.
