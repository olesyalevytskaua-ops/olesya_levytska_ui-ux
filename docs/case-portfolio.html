02 / DESIGN DECISIONS

Make the work easy to evaluate.

I separated selected professional work from independent experiments, kept the CV and contact routes explicit, and translated long project narratives into readable HTML with supporting product visuals.

The portfolio’s typography, spacing and navigation form the shared frame. Product colours, mockups and illustrations express each project’s identity inside that frame—not a different website to learn on every case.

03 / DESIGN TO DELIVERY

AI-assisted. Personally owned.

I use Claude, Cursor and ChatGPT to help explore and implement changes, then review the output and refine the interface. Source changes move through GitHub branches and pull requests before publication on GitHub Pages.

The implementation includes semantic page structure, visible keyboard focus, responsive layouts, theme controls and reduced-motion alternatives. These are implementation choices, not a claim of independently certified WCAG compliance.

Next validation: test whether recruiters can identify my role, find a relevant case and open the CV without help; then measure case visits, CV clicks and contact actions once reliable analytics are available.
